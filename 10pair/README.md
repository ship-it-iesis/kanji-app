# 10の ペア ゲーム

小学1年生（特別支援学級）向けの、10の合成分解（1と9、2と8、3と7、4と6、5と5）を覚えるゲームです。

- `index.html` を開くだけで遊べます（1ファイルで完結。通信はしません）。
- Chromebook のタッチ画面で動かすことを想定しています。
- 1回10問。タイムに応じて星が1〜3つ。星で「うさぎのおうち」の家具を買って飾れます。
- 記録（星・家具・タイム）は、その端末のブラウザに保存されます。個人情報は扱いません。

## 先生向けの設定

`index.html` の先頭近くにある `CFG` で、問題数や星の基準（30秒以内=3つ、60秒以内=2つ）を変えられます。
