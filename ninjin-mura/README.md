# ぴょんぴょん にんじんむら

小学1年生（特別支援学級）向けの、くり上がりのあるたし算・くり下がりのあるひき算のゲームです。

- `index.html` を開くだけで遊べます（1ファイルで完結。通信はしません）。
- Chromebook のタッチ画面で動かすことを想定しています。
- 1回10問。タイムに応じて星が1〜5つ（25秒以内=5、30秒以内=4、40秒以内=3、50秒以内=2、それより遅いと1）。
- にんじんが100本たまると収穫パーティ。星10個がもらえて、星でおみせの「かざり」を買って畑に置けます。
- バッジ、ミッション、記録（棒グラフ＝一発正解の数、折れ線＝かかった時間）があります。
- 記録は、その端末のブラウザに保存されます。個人情報は扱いません。
